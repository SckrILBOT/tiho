# Тихо

«Тихо» — интерактивное звуковое пространство для работы и чтения. В ночном купе можно слушать дождь и стук колёс, менять свет, открывать форточку и вести записи в блокноте.

## Демо

[Открыть «Тихо»](https://sckrilbot.github.io/tiho/)

## Что можно сделать в купе

- Включить звук и настроить громкость. Открытая форточка меняет звучание дождя и ветра.
- Остановить поезд. Лес за окном замирает, стук колёс затихает, а дождь продолжает падать медленнее.
- Листать блокнот и запускать рабочие сессии на 25 или 50 минут.
- Включить режим погружения, чтобы скрыть основные элементы управления.

Записи и настройки хранятся в браузере. Таймер сбрасывается при перезагрузке.

## Локальный запуск

Проект написан на HTML, CSS и JavaScript. Для локального просмотра откройте `public/index.html` или запустите сервер из корня репозитория:

```sh
python -m http.server 4173 --bind 127.0.0.1 --directory public
```

Сайт будет доступен по адресу [localhost:4173](http://127.0.0.1:4173/). Команда `python scripts/build-site.py` копирует файлы для публикации в `dist/`.

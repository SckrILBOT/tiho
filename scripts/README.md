# Локальные проверки

Запускать из корня проекта. Нужны Node.js 22+ и установленный Chrome/Edge/Chromium.

Браузерный адаптер по умолчанию берётся из `~/.agents/skills/design-taste-frontend/scripts/lib/cdp.mjs`. Если он установлен в другом месте, задать `TIHO_BROWSER_ADAPTER` — абсолютный путь к файлу адаптера. Имя пользователя и папка проекта не зашиты в актуальные браузерные сценарии; file:// URL строится относительно исходника.

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory public
# Во втором терминале:
node scripts/check-audit-fixes.mjs
node scripts/check-fullscreen.mjs
```

`check-audit-fixes.mjs` проверяет отрицательные сценарии из отчётов от 04.11.2026. `check-fullscreen.mjs` — основной пользовательский путь. Сценарии статической страницы и ранних взаимодействий отражают предыдущие этапы и не являются проверкой нового модального входа.

Подготовка ассетов использует Python, Pillow, numpy и imageio-ffmpeg. При необходимости установить эти зависимости в отдельное окружение. `prepare-audio.py` работает с уже сохранёнными исходниками в `public/assets/audio/`; повторно скачивать их не нужно. `redesign-layout.py` — одноразовая миграция прошлой версии, повторно её не запускать.
